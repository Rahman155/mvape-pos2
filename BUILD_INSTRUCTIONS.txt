================================================================================
TROUBLESHOOTING
================================================================================

If BUILD.ps1 doesn't run:
1. Open PowerShell as Administrator
2. Run: Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
3. Try running BUILD.ps1 again

If build fails with "cannot find":
1. Make sure you're in the project root directory
2. Check you have internet connection (npm/pnpm needs to download packages)
3. Try deleting node_modules folders and pnpm-lock.yaml, then run again

If PowerShell force closes:
1. Use BUILD_ALL.bat instead
2. Or run manually:
   - cd packages\backend && pnpm install && pnpm run build
   - cd packages\frontend && pnpm install && pnpm run build
